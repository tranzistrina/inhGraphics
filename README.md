# ТЗ: плагин inhGraphics (Minecraft 1.21.1) — УТВЕРЖДЕНО

## 1. Цель
Серверный плагин для Paper 1.21.1 (Java 21), управляющий **индивидуальным**
(видимым только конкретному игроку) окружением: временем суток, погодой,
дальностью прорисовки и туманом из частиц. Всё — чистая косметика: игровая
логика сервера (горение мобов, спавн, сон, реальная погода мира) не меняется.

## 2. Платформа
- Paper 1.21.1 (paper-api), Java 21.
- Только команды, без GUI.

## 3. Функции

### F1. Индивидуальное время суток
- `/igtime day|night|noon|midnight|<тики>|reset [ник]`
- Без ника — к самому себе; с ником — админ меняет другому.
- `reset` — вернуть мировое время (`resetPlayerTime`).

### F2. Индивидуальная погода
- `/igweather clear|rain|thunder|reset [ник]`
- `clear/rain` — Bukkit `setPlayerWeather`.
- `thunder` — дождь + персональный уровень грома + периодические раскаты грома
  (`Sound.ENTITY_LIGHTNING_BOLT_THUNDER`, чистый API, без урона и молний).
- Звук грома отключаемо: `config.yml -> thunder-sound: true/false`.

### F3. Индивидуальная дальность прорисовки
- `/igrender <2–32|reset> [ник]`
- Сервер перестаёт слать игроку чанки за указанным радиусом → видимый «обрыв
  мира». Маскировать туманом НЕ требуется (решено): обрыв остаётся обрывом.
- Исходное значение запоминается и восстанавливается при reset.

### F4. Персональный туман из частиц
- Чистым плагином клиентский туман недоступен, поэтому туман имитируется
  частицами, которые видит только целевой игрок.
- `/igfog on|off [ник]` — включить/выключить.
- `/igfog density <1–10> [ник]` — плотность.
- Настройки в config.yml: тип частицы (по умолчанию CLOUD), высота слоя,
  радиус спавна.

## 4. Права
Только администраторы: право `inhgraphics.admin` (по умолчанию op).
Обычные игроки себе ничего менять не могут (решение от 25.08).

## 5. Сохранение состояния (навсегда)
- `players.yml` по UUID: время, погода, дальность рендера, туман+плотность.
- Восстановление при входе игрока на сервер.
- Сброс: `/igreset <ник>` — все настройки игрока; `/igreset all` — всем онлайн
  и очистка файла.

## 6. Командная сводка
| Команда | Действие |
|---|---|
| /igtime day\|night\|noon\|midnight\|<тики>\|reset [ник] | персональное время |
| /igweather clear\|rain\|thunder\|reset [ник] | персональная погода |
| /igrender <2–32>\|reset [ник] | персональная прорисовка |
| /igfog on\|off\|density <1–10> [ник] | персональный туман |
| /igreset <ник\|all> | полный сброс настроек |
