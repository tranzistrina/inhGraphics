# inhGraphics

Paper 1.21.1 plugin (Java 21) for per-player visual environment effects.

## Repository layout

```text
inhGraphics/
├── plugin/
│   ├── build.gradle
│   └── src/
│       └── main/
│           ├── java/
│           │   └── ru/khozain/inhgraphics/
│           └── resources/
│               ├── config.yml
│               └── plugin.yml
├── dist/
│   └── inhGraphics-1.0.0.jar
├── .gitignore
└── README.md
```

The repository intentionally contains only plugin source, build configuration and the distributable JAR. Runtime servers, logs, backups and generated build directories are not tracked.
