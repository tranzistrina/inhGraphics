# inhClientPATHgraphics

Необязательный Fabric client-only мод для Minecraft 26.2.

## Установка

Скопировать `dist/inhClientPATHgraphics-1.0.0.jar` в папку `mods` клиента вместе с Fabric Loader 0.19.3 и Fabric API 0.156.0+26.2.

Без этого мода vanilla-клиенты продолжают работать с `inhGraphics` как раньше.

## Что делает

- принимает от `inhGraphics` персональный лимит дальности;
- ограничивает локальный vanilla render distance, поэтому Bobby перестаёт держать лишние fake chunks;
- временно переключает Bobby на немедленную выгрузку кэша;
- временно отключает Voxy LOD-рендер при персональном ограничении и восстанавливает его при сбросе/выходе;
- отправляет серверу список загруженных Fabric-модов по plugin channel;
- не является полноценным античитом: список модов добровольный и не может считаться доказательством.

Плагинный канал: `inhgraphics:sync` / `inhgraphics:mods`.
